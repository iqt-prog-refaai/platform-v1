أساسيات تقنية الواجهة الأمامية (Frontend Technology Basics)

في الدرسين السابقين، تعرفت على دور الواجهة الأمامية (Front-end) وكيف تتواصل مع الخادم عبر الشبكة. وفي هذا الدرس سنتعمق داخل الواجهة الأمامية نفسها لنكتشف كيف تتضافر HTML و CSS و JavaScript لبناء صفحة الويب، وكيف تجعل الممارسات الحديثة مثل HTML الدلالية والتصميم المتجاوب وأطر العمل (Frameworks) صفحات الويب ذات معنى وقابلة للتكيف وفعّالة في التطوير.

السؤال الرئيسي للدرس (خريطة الدرس · ص 62)
كيف تعمل HTML و CSS و JavaScript معاً لبناء صفحة ويب، وما الذي يجعل الواجهة الأمامية الحديثة ذات معنى وقابلة للتكيف وفعّالة في البناء؟
الفكرة الأساسية للدرس (خريطة الدرس · ص 62)
تُبنى صفحة الويب من HTML (البنية)، و CSS (المظهر)، و JavaScript (السلوك)؛ وتضيف الواجهة الأمامية الحديثة HTML الدلالية والتصميم المتجاوب وأطر العمل.

أهداف التعلم:

  • 01. شرح الأدوار المميزة لكل من HTML و CSS و JavaScript في بناء صفحة الويب.
  • 02. شرح كيف تسهم لغة HTML الدلالية (Semantic HTML)، والتصميم المتجاوب (Responsive Design)، وأطر العمل (Frameworks) في تحسين الواجهة الأمامية الحديثة.

المفاهيم والمصطلحات الأساسية في الدرس:

أدوار HTML و CSS و JavaScript في بناء صفحة الويب

تؤدي كلٌّ من HTML و CSS و JavaScript أدواراً مختلفة ومتكاملة في صفحات الويب. ملاحظة هامة من الكتاب المدرسي: ليس من الضروري أن تستخدم الصفحة الثلاث كلها معاً؛ إذ يمكن أن تستخدم HTML وحده لعرض نص بسيط، أو أن تجمع بين HTML و CSS و JavaScript بحسب الوظائف التي تحتاج إليها.

التقنية الدور الوظيفي في صفحة الويب التشبيه الهندسي بالمبنى (ص 62)
HTML
البنية (الهيكل)		 يحدد بنية (هيكل) صفحة الويب، ويصف عناصر المحتوى الأساسية مثل العناوين، والفقرات، والقوائم، والصور، والروابط. 🏗️ هيكل مبنى (الأعمدة والجدران والغرف الأساسية التي تُشكّل المبنى).
CSS
المظهر (التنسيق)		 يحدد مظهر صفحة الويب وتصميمها المرئي، مثل الألوان، والتخطيط، والحجم، والخطوط، والتباعد. 🎨 الديكور الداخلي والخارجي لمبنى (الطلاء، الألوان، الإضاءة، وترتيب الأثاث).
JavaScript
السلوك (التفاعلية)		 يضيف السلوك والتفاعلية إلى صفحة الويب، ويُفعّل الاستجابات عند الضغط على الأزرار، وتحديثات جزء فقط من الشاشة دون إعادة تحميل الصفحة كاملة. ⚡ أنظمة الكهرباء والسباكة في مبنى (المصاعد، الأبواب الآلية، ومفاتيح الإضاءة التي تستجيب لك).

ثانياً · ص 63

        
HTML الدلالية (Semantic HTML)، إمكانية الوصول، ومحركات البحث

        

          في صفحات الويب الحديثة، لا نكتفي بوضع العناصر داخل صناديق عامة غير معبّرة (<div>)، بل نستخدم عناصر HTML الدلالية التي توضح وظيفة كل جزء من أجزاء الصفحة ومعناه، مثل:
          <header> في أعلى الصفحة، و <nav> للتنقل، و <main> للمحتوى الرئيس، و <footer> في أسفل الصفحة.
        

      


      
      

        

          

            
الفائدة الأولى · Accessibility

            
1. تحسين إمكانية الوصول (Accessibility)

            

              إمكانية الوصول تعني تصميم المحتوى والواجهة بحيث يمكن لأصحاب القدرات والاحتياجات المختلفة استخدامها، بمن فيهم ذوو الإعاقة.
              يساعد HTML الدلالي برامج قارئ الشاشة (Screen Reader) على فهم بنية الصفحة والتنقل المباشر بين أقسامها (كالقفز مباشرة إلى قائمة التنقل <nav> أو المحتوى الرئيس <main>)، مع الحاجة إلى ممارسات وصول أخرى أيضاً (مثل النصوص البديلة للصور وتباين الألوان).
            

          

        


        

          

            
الفائدة الثانية · SEO (Search Engine Optimization)

            
2. مساعدة محركات البحث على فهم المحتوى

            

              تحسين محركات البحث (SEO) هو مجموعة الممارسات التي تجعل الصفحة أيسر في الفهرسة والظهور في نتائج البحث.
              قد يساعد HTML الدلالي محركات البحث على فهم بنية المحتوى وأهمية كل قسم بصورة أفضل، لكنه لا يضمن ترتيباً أعلى في نتائج البحث بمفرده (تنبيه امتحاني مهم جداً في الكتاب ص 63).

توقف وفكر · ص 63

          

            لماذا يفهم قارئ الشاشة الصفحة بشكل أفضل عندما نستخدم <header> و <nav> و <main> بدلاً من صناديق عادية (<div>)؟
          

        

        

          
          

            لأن الصناديق العادية (<div>) هي حاويات عامة لا تحمل أي معنى وظيفي، فلا يعرف قارئ الشاشة ما إذا كان الصندوق يمثل قائمة تنقل أم ترويسة أم محتوى رئيسياً. أما الوسوم الدلالية (<header>، <nav>، <main>) فتعرّف دور كل منطقة بوضوح كمعالم (Landmarks)، مما يتيح للمستخدم الكفيف أو ضعيف البصر فهم هيكل الصفحة والقفز مباشرة إلى المحتوى الرئيس دون الاضطرار لقراءة كل الروابط في كل مرة.
          

        

      

    


    
    

      

        
ثالثاً · ص 64

        
التصميم المتجاوب (Responsive Design) ونهج الأولوية للجوال

        

          التصميم المتجاوب (Responsive Design) هو مفهوم تصميمي يُضبط فيه تخطيط الصفحة تلقائياً وفقاً لأحجام الشاشات المختلفة، مثل أجهزة الكمبيوتر، والهواتف الذكية، والأجهزة اللوحية؛ مما يساعد الصفحة على التكيف مع كل شاشة وتحسين سهولة استخدامها.
        

      


      

        📱 نهج الأولوية للجوال (Mobile-First Approach · ص 64):
        يستخدم كثير من الناس الويب عبر الهواتف الذكية، لذلك يراعي المطورون الشاشات الصغيرة منذ بداية التصميم قبل التوسع للشاشات الأكبر، ويُسمى ذلك أحياناً نهج الأولوية للجوال (Mobile-First).

رابعاً · ص 64

        
أطر العمل والمكتبات الحديثة (Frameworks & Libraries)

        

          إطار العمل (Framework) هو بنية توفر مسبقاً وظائف ومكونات شائعة الاستخدام، وذلك لجعل عملية تطوير تطبيقات الويب أكثر كفاءة.
          عند استخدام إطار عمل، لا يحتاج المطورون إلى كتابة كامل الكود البرمجي من الصفر، ويمكنهم التطوير بكفاءة أكبر عبر بناء الصفحات من مكونات قابلة لإعادة الاستخدام.
        

      


      
      

        

          
            

              المكتبة / إطار العمل
              التصنيف الهندسي
              الوصف والخصائص (كما ورد في الكتاب المدرسي · ص 64)
            

          
          
            

              React
              مكتبة JavaScript لواجهات المستخدم
              مكتبة JavaScript لبناء واجهات المستخدم من مكونات قابلة لإعادة الاستخدام (Reusable Components) وتحديثها تلقائياً عند تغير البيانات.
            

            

              Vue
              إطار عمل متدرج لتطوير الويب
              له بنية بسيطة ويتيح بناء تطبيقات الويب تدريجياً بدءاً من ميزات صغيرة وصولاً إلى تطبيقات متكاملة.
            

            

              Next.js
              إطار عمل مبني على React
              إطار مبني على React لبناء تطبيقات ويب متكاملة، ويوفر التوجيه (Routing) وطرقاً مختلفة لعرض الصفحات والعمل على الخادم والعميل.
            

          
        

      


      
      

        
خلاصة الفكرة الرئيسة · ص 64

        صفحة الويب الحديثة هي تركيبة متكاملة، وليست تقنية واحدة:
        HTML يبني بنيتها، و CSS ينسّق مظهرها، و JavaScript يجعلها تفاعلية — بينما تجعل HTML الدلالية والتصميم المتجاوب وأطر العمل بناءها ذا معنى وقابلاً للتكيف وفعّالاً.

سؤال على نمط الامتحان [6 درجات] · ص 65

            

              اشرح كيف تساهم كل من HTML و CSS و JavaScript في صفحة مكتبة تعرض قائمة كتب، وتكون منسّقة، وتُصفّي النتائج أثناء كتابة المستخدم.
            

            
حاول صياغة إجابتك بتقسيم الدرجات الـ 6 (درجتان لكل تقنية: اسم التقنية + دورها في صفحة المكتبة)، ثم اضغط لعرض نموذج التصحيح:

          

          

            
            

              

                
✅ HTML [درجتان]: تُنشئ البنية والعناصر الأساسية في صفحة المكتبة، مثل عنوان الصفحة، وحقل إدخال البحث، وقائمة الكتب وعناوينها.

✅ JavaScript [درجتان]: تضيف السلوك التفاعلي، حيث تكتشف ما يكتبه المستخدم في مربع البحث وتقوم بتصفية وتحديث قائمة الكتب المعروضة فوراً على الشاشة دون إعادة تحميل الصفحة.

              

            

          

        

      


      
      

        

          

            
فكّر كمهندس (ابحث ثم قرر) · ص 66

            
تصميم صفحة ويب لنادي الطلاب

            

              تريد صفحة النادي أن تعرض: (1) قائمة بالفعاليات، و(2) ألوان النادي وتخطيطه، و(3) عدّاد تسجيل يتحدث مباشرة عند انضمام طالب.
              أي تقنية ستستخدم لكل جزء؟ وهل تضعها في ملفات منفصلة أم ملف واحد؟
            

          

          

            
            

              
    
                
  • قائمة الفعاليات والعناوين: نستخدم HTML (ويُفضل HTML الدلالية مثل <main> و <ul>).
    • 
                
  • ألوان النادي وتخطيطه المتجاوب: نستخدم CSS لضبط الهوية اللونية وتجاوب الصفحة مع هواتف الطلاب.
    • 
                
  • عدّاد التسجيل المباشر: نستخدم JavaScript للاستماع لحدث النقر على زر «انضمام» وتحديث رقم العداد لحظياً.
    • 
                
  • تنظيم الملفات: يُوصى هندسياً بـ فصلها في ملفات مستقلة (index.html، style.css، app.js) لتسهيل الصيانة وتقسيم العمل وإعادة الاستخدام، بينما يُستخدم الدمج في ملف واحد فقط في النماذج الأولية الصغيرة جداً.

تحليل موقع إخباري أو تعليمي

            

              عند زيارة موقع إخباري حديث من هاتفك وحاسوبك، كيف تلاحظ عمل التقنيات الثلاث والتصميم المتجاوب و HTML الدلالية معاً؟
            

          

          

            
            

              
    
                
  • HTML الدلالية: تقسيم الموقع إلى ترويسة أخبار عاجلة (<header>)، شريط أقسام (<nav>)، والمقالات الرئيسة (<main> / <article>) مما يساعد قارئات الشاشة ومحركات البحث.
    • 
                
  • CSS والتصميم المتجاوب: على شاشة الكمبيوتر تظهر الأخبار في 3 أعمدة مع قائمة أفقية، بينما على الهاتف الذكي تتحول تلقائياً إلى عمود رأسي واحد مريح للقراءة مع قائمة مطوية.
    • 
                
  • JavaScript: تحديث شريط الأخبار العاجلة أو نتائج المباريات لحظياً وتبديل الوضع الليلي/النهاري دون إعادة تحميل الصفحة.
